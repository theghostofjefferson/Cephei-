# CEPHEI website

A plain HTML/CSS/JS skeleton. No build step and no dependencies: open `index.html` in a browser.

## Pages
- `index.html` — home
- `about.html` — aim, name, team
- `programs.html` — teaching, school camps, awareness
- `contact.html` — enquiry form (opens the visitor's email app)

`css/style.css` holds all styling (colors and fonts are at the top). `js/site.js` holds the menu and the contact form.
